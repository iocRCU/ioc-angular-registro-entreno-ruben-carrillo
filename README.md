# TTracker

## Autor/a

Ruben Carrillo

## Descripción

Aplicación de seguimiento de entrenamientos con registro de ejercicios, volúmenes, cargas y tiempos. Permite gestionar variantes de ejercicios y mantener un historial de progresión.

## Versiones utilizadas

| Herramienta | Versión |
|-------------|---------|
| Angular | 19 |
| TypeScript | 5.x |
| Node.js | 20.x |
| npm | 10.x |
| Git | Latest |
